# Prostate 3D Dataset segmentation with original 3D UNet

## Description  

This repository contains a data loading, training, and evaluation script for an original 3D UNet meant to segment the CSIRO ["Labelled weekly MR images of the male pelvis"](https://data.csiro.au/collection/csiro:51392v2?redirected=true) dataset. 

### Inputs
The required input files match the format of the images and labels stored in the `HipMRI_study_complete_release_v1.zip` file. More precisely, it requires the files to be named in the scheme `Case_XXX_WeekX` followed by other, unnecessary information. This is so the data loader can find the correct files, and so that the image and label files can be linked consistently.

### Outputs  
Running predict.py with a working `best_model.pth` file generated by `train.py` will result in the `/predictions` folder in the root directory of the python scripts being generated. This folder will contain prediction masks for a randomly chosen 20% of the dataset images. These masks can be viewed in a medical image viewer with NiFTi support like ITK-SNAP, which was used for the testing of this script.

### Pre-processing
Pre-processing is carried out inside the `dataset.py` file. Images and labels ***must*** be pre-processed before `train.py` can be ran. This pre-processing converts the nii.gz format images and labels into PyTorch Tensor .pt files and downsamples them. This has speed advantages when doing more than a single run of `train.py` due to removing the need to process the files while training. This pre-processing also downsamples images by a scale of 0.5, which helps with memory requirements and significantly speeds up training, while not harming model accuracy significantly.

### Requirements to run this project via pipreqs:  
monai==1.5.1  
nibabel==5.3.2  
numpy==2.3.4  
scipy==1.16.3  
torch==2.8.0  
tqdm==4.67.1

This project has been developed and tested using exclusively the dataset files in `HipMRI_study_complete_release_v1.zip`. It working for other datasets with renamed files cannot be guaranteed due to differences in the dimensions and number of classes in the ground truth labels.
